# CHROMEFORM

Интерактивный генератор объёмных Y2K-форм: нарисуйте силуэт от руки или загрузите SVG/изображение, выберите металлическое покрытие, добавьте собственную текстуру и экспортируйте результат.

## Возможности

- Рисование свободного контура с мгновенной 3D-экструзией.
- Загрузка SVG с сохранением контуров, а также PNG/JPG/WEBP с извлечением силуэта.
- Пресеты форм: blob, star, heart, flower, diamond.
- Металлические Y2K-материалы, свет, глубина, скругление и зерно.
- Своя texture map для поверхности.
- Экспорт PNG с прозрачным фоном (длинная сторона 3840 px) и 6-секундного WEBM-видео.

## Запуск

```bash
npm install
npm run dev
```

Сборка для продакшена:

```bash
npm run build
```
